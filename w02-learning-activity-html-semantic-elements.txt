HTML Heading Tags (h1-h6):
Used to create titles and section headers on web pages
Search engines also use heading tags to understand the structure and importance of your content

H1: most important heading
H6: less important heading
The number describe rank, not size

The Six Heading Tags
h1 – The main title of your webpage. Use only one h1 tag per page.
h2 – Major section headings that divide your content into main parts.
h3 – Subsection headings that break down h2 sections into smaller parts.
h4 – Minor headings for detailed subsections within h3 sections.
h5 – Small headings for very specific content areas.
h6 – The lowest-level heading, rarely used but available for detailed organization.


Why you should not skip heading levels:
  Do not jump from h2 directly to h5 without using h3 and h4 first.
  Skipping heading levels can cause problems for people who use sreen readers to navigate websites
  Search engines also prefer websites that use proper heading structure because it helps them understand what your content is about.
   Following the correct heading order makes your website more accessible and easier to find in search results.

W02 Learning Activity: CSS Units of Measurement
-----------------------------------------------

* Numeric Values - Two main types:
 Absolute length: 
  - pixels ej. 10px is not relative to anything else and is typically the same size on most devices 
   
 Relative length:
  - percentage: 90% - are dependent on their items, including the parent, sibling, or the size of the viewport

* Common length units include:

  px: pixels, an absolute unit.

  %: a percentage of the size of the parent element.
  em: relative to the current font size of the element.
  rem: relative to the font size of the root (html) element.
  vw and vh: 1% of the width or height of the viewport.

* Video Units of Measurements

Color Values
------------

keyword: antiquewhite, burlywood, yellow, lightyellow, etc.
hexadecimal RGB (red, green, blue): #faebd7
where the first two characters are the red value, the next two are the green value, and the last two are the blue value in hexadecimal (base 16) format. Each pair ranges from 00 to FF (0 to 255)
RGB: rgb(250 235 215) or, with transparency, rgb(250 235 215 / 50%)
where r is a red value ranging from 0 to 255, g is a green value ranging from 0 to 255, b is a blue value ranging from 0 to 255, and the optional last value is the alpha (opacity) value ranging from 0 to 1 (0% to 100%)
HSL: hsl(34 78% 91%) or hsl(34 78% 91% / 50%)
where h is the hue (0 to 360), s is the saturation (0% to 100%), l is the lightness (0% to 100%), and the optional last value is the alpha value (0 to 1 or 0% to 100%)

W02 Learning Activity: CSS Box Model
====================================

The CSS Box Model is a box that wraps around every element
From the inside out (desde adentro hacia afuera),
the model defines how the content, padding, border and margin are rendered

              THE BOX MODEL

    +---------------------------------------+
    |                                       |
    |                 MARGIN                |
    |                                       |
    |    +-----------------------------+    |
    |    |                             |    |
    |    |            BORDER           |    |
    |    |                             |    |
    |    |    +-------------------+    |    |
    |    |    |                   |    |    |
    |    |    |      PADDING      |    |    |
    |    |    |                   |    |    |
    |    |    |   +-----------+   |    |    |
    |    |    |   |           |   |    |    |
    |    |    |   |  CONTENT  |   |    |    |
    |    |    |   |           |   |    |    |
    |    |    |   +-----------+   |    |    |
    |    |    |                   |    |    |
    |    |    +-------------------+    |    |
    |    |                             |    |
    |    +-----------------------------+    |
    |                                       |
    +---------------------------------------+

All elements have a rectangular box around them.
each box also has a default width and height

Block level elements have a default width of 100
In-line and inline block elements will expand and contract to accommodate their content

The default height of an element is determined by its content it will expand
and contract vertically as necessary to accomodate it content.

El box-model puede ser cambiado para calcular el padding y el border 
en el width general con la propiedad:

box-sizing: border-box

content: This is where the text and images appear.
padding: This is the area around the content and separates the content from the border.
border: The border goes around the padding and separates the padding from the margin.
margin: This is the transparent space outside of the border that separates the element from its neighbors.


Most developers find border-box easier to work with, so it is common to apply it to every element at the top of a stylesheet:

* {
  box-sizing: border-box;
}


CSS Shorthand Notation
----------------------
CSS shorthand notation is generally considered best practice for conciseness and readability.
However, longhand notation has its uses and can be more appropriate in certain situations where specificity is needed.

Common Border Shorthand
-----------------------
border: 1px solid rgb(0 0 0 / 10%);
This applies a 1-pixel solid black border at 10% opacity around the element, which appears as a faint gray line.
